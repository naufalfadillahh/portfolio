**Live:** https://naufal-fadillah.vercel.app

## Isi

- Profil, pendidikan (S1 Informatika Universitas Gunadarma, IPK 3,64), dan kontak
- Riwayat pengalaman dalam bentuk tabel
- Tech stack dan tools beserta bukti sertifikatnya

- 36 lisensi dan sertifikat (BNSP, Universitas Gunadarma, Dicoding, IBM SkillsBuild) dengan filter, pencarian, dan urutan
